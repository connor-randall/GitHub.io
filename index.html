Weasley Clock

A real version of the clock from Harry Potter, with one hand for each of my brothers pointing to Home, Work, Traveling, Up to No Good, or Mortal Peril. Phones report location through OwnTracks geofences to a Flask backend on my Proxmox cluster, and an ESP32 moves each 270° servo hand to match.

  • ESP32
  • Servos
  • Flask
  • OwnTracks
  • Cloudflare Tunnel

BirdNET Detectors

Two Raspberry Pis with USB mics run BirdNET-Pi around the clock to identify birds by their calls. Each one pushes detections, audio clips, and species photos to this site every 10 minutes without opening any inbound ports.

  • Raspberry Pi
  • BirdNET-Pi
  • Python
  • Enviro+
  • Git

Homelab

A self-hosted stack on Proxmox VE, with every service running in its own VM or LXC container. It runs a Plex media server, Grafana monitoring, and Folding@Home, with traffic routed through a Gluetun VPN.

  • Proxmox VE

  • Plex

Deslopify

A Chrome extension that flags AI-generated and low-quality posts on X. It scores each post from 0 to 100 using 38 individually toggleable tells, and runs entirely offline with no API key or network requests.
